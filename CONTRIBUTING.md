# Contributing

Keep changes focused and preserve existing SMP_LastFM behavior unless a change
is intentional and documented.

Before submitting changes:

1. Test the script in Spider Monkey Panel.
2. Check the SMP console for JavaScript errors.
3. Test a new track start.
4. Test the context menu.
5. Test Panel properties and Configure.
6. Test Top Artist scrolling.
7. Test **Avatar > Download Avatar**.
8. Test **Avatar > Restore Default Avatar**.
9. Confirm a downloaded avatar fits within the 126 x 126 px avatar area.
10. Update the changelog when behavior changes.
11. Update the built-in Help when user-facing behavior or Properties change.

Never commit personal Last.fm API credentials or downloaded personal avatar
files.
